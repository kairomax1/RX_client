# Lines starting with # are notes.

# Only the names a game's own client talks to belong here: the launcher, the
# sign-in, the shop, the matchmaker and the content servers. The name of the
# publisher's marketing site does not, and neither does anything a game shares
# with every other site (a general CDN), because that would drag unrelated
# traffic into the tunnel.

# rules carry the parts that can be named; the rest of the game is covered by
# the choice the owner makes for the whole connection in gaming mode.
