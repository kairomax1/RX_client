# Iranian apps, as this phone can know them.
#
# One entry per line. A line with a dot in it is a package name: an app matches
# when its package is that name, or begins with it followed by a dot. A line
# without a dot is a piece of an app's name, and matches whether the phone shows
# that name in Persian or in the Latin alphabet. Lines starting with # are notes.
#
# These apps are the ones that must not arrive from a foreign address: a bank
# that sees a foreign address refuses the login, and a shop that sees one shows
# the wrong prices. The app picks them out and sends them on the phone's own
# line; the owner can change every one of them afterwards.
