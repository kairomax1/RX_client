# One entry per line: "domain:name" matches the name and everything under it,
# "full:name" only that name. Lines starting with # are notes.
#
# These never go through the tunnel. An Iranian site that sees a foreign address
# either refuses the connection (most banks do), asks for a code it cannot send
# abroad, or shows everything in the wrong currency and city. Sending them out
# on the phone's own line is both faster and the only way they work at all.
#
# ".ir" as a whole is included: a name under it is run for an Iranian audience by
# definition. The rest are Iranian services that happen to sit on another ending.
