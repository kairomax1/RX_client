# Advertising, tracking and telemetry domains.
#
# One entry per line: "domain:name" matches the name and everything under it,
# "full:name" only that name. Lines starting with # are notes. Only host names
# belong here; anything with a path is dropped when the file is read.
#
# These are the names adverts, ad measurement and trackers are fetched from.
# Blocking them stops the advert, the counter behind it and the profile that
# follows the phone around, and leaves the site or the app itself working.
# Deliberately absent: the names a site needs in order to work, even when the
# same company also sells adverts (youtube.com and api.spotify.com for example).
